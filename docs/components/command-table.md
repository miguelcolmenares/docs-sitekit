# CommandTable

## About

A list of commands and what each one does, in two columns from the `md` width and one under it. A row can have a note, which is shown from the `lg` width.

## Accessibility

- It is a list, and each command is a `<code>` element, not a control.
- The note is hidden under the `lg` width, so put anything a reader needs in `text`.
